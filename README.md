# 抖音TV —— 电视上的抖音网页版壳子

把抖音网页版装进 Android TV / 电视盒子，开机点图标直接进视频，遥控器上下键刷推荐流。
原理和油桃TV那类软件一样：**自带内核适配层的 WebView 壳**，不是抓接口、不是破解。

## 键位

影院态（正常刷视频时）：

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 上一条 / 下一条 |
| 确认（短按） | 暂停 · 播放 |
| 确认（长按） | 画面模式：完整显示（左右黑边）↔ 铺满（上下裁切） |
| ← / → | 后退 / 前进 10 秒 |
| 菜单（短按） | 影院态开 / 关 |
| 菜单（长按） | 自检浮层：WebView 内核版本、UA、切换策略、当前状态 |
| 返回 | 关浮层 → 退影院态 → 网页后退 → 退出 |

首次进入是**扫码登录页**，此时应用会自动退回网页模式（方向键交给页面做焦点导航），
用手机抖音扫电视上的二维码；登录成功、视频开始播放后自动进入全屏影院态。
登录态存在应用私有目录，之后开机直进。

## 云端构建（推荐，本机不用装任何东西）

1. 注册/登录 [github.com](https://github.com)，New repository，名字随意（如 `douyin-tv`），选 **Public**，勾选 *Add a README*。
2. 仓库页 **Add file → Upload files**，把本工程 `app/`、`.github/`、以及 `build.gradle`、`settings.gradle`、`gradle.properties`、`.gitignore` 全部拖进去，Commit。
3. 仓库顶部 **Actions** 标签页会自动开始构建（约 3~6 分钟）。
4. 点开那次运行 → 页面底部 **Artifacts** → 下载 `douyin-tv-apk` → 解压得到 `app-debug.apk`。

改了代码重新上传即自动重编；`versionCode` 用日期式，新包可直接覆盖安装，不用先卸载。

## 装到电视

U 盘插电视 → 文件管理器找到 apk → 安装（雷鸟/灵犀OS 需先在 设置 → 关于/安全 里允许"安装未知来源应用"）。

## 结构

```
MainActivity.java     遥控器按键分发、原生 Fullscreen 回调、内核自检、Cookie 持久化
assets/douyin-tv.js   影院态：把 <video> 提到全屏、上下键切流（四策略择优）、HUD
tools/dtv-test.js     假 DOM 回归测试：`node tools/dtv-test.js app/src/main/assets/douyin-tv.js`
```

抖音改版后 JS 适配层最容易失效，改完先用 `tools/dtv-test.js` 跑一遍再上传构建。

分层原因：抖音网页版的 DOM 结构会变，页面侧的适配全靠 JS；按键和窗口是原生职责，
两边只靠 `window.__dtv` 和 `AndroidTV` 两个名字约定，任何一侧改版只改一侧。

## 已知边界

- 依赖电视的系统 WebView 版本。内核低于 Chrome 90 时抖音网页版大概率白屏，
  应用启动会直接把这个判断显示出来（长按菜单键也能看）。
- 竖屏视频在 16:9 电视上必然要么留黑边要么裁切，没有第三种物理可能。
- 抖音若对"桌面浏览器 + 无鼠标"的组合加强风控，可能弹滑块验证——那一步需要手机扫码
  登录态来绕开，壳子层面无法代劳。

## 合规

自用、不抓取接口、不二次分发、不去水印不下载，风险很低。别把 APK 拿出去卖或传播。
